## Agent skills

### Issue tracker

Issues live as GitHub issues in `Pasitearko/white-album-diary`; this working copy is not a git clone, so pass `--repo Pasitearko/white-album-diary` explicitly. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical roles, one label each: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` plus `docs/adr/` at the repo root. See `docs/agents/domain.md`.
